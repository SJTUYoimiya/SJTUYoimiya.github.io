## 网站介绍

### 网站名称

本站名为「五洲湖底」，该词来源于博主家乡的一项市政工程——五洲湖，在博主中学时代时，它因为和博主名字拼音缩写相同而成为博主的一个外号。在给网站取名时，没由来地，博主突然想起了这个名字，又加了一个「底」字，一方面寓意这里是向湖底一样常人不会踏足的地方，可以记录一些不会在人前提起的感想；另一方面也有“考试挂了就跳湖”的调侃成分在。

至于本站的 slogan——**去把这个不完美的故事，变成我们所期望的样子！**——来自米哈游游戏《崩坏 3》中的经典台词。游戏里，从实验体 K423 到薪炎之律者，纵使留给她的现实非常残酷，即便她们面临的世界并不美好，但她们依然在努力地去改变这个世界，亲手写下自己的命运。博主深知无法像游戏动漫里那样逆天改命、改变世界，面对同样并不美好的现实世界，也许痛苦与挣扎才是人生的主旋律。但博主仍然希望能在这个不完美的故事里，努力将属于自己的那一篇中，留下自己所期望的故事。

### 内容安排

本站内容共分为三大类：技术日志、学习笔记与生活日记。

1. **技术日志**：记录博主在程序调试、debug 过程中遇到的问题及解决方案，以及环境配置、系统管理等过程的记录;
2. **学习笔记**：整理博主在学习、实习中的笔记与经验，包括数学、编程、DL、算法等领域;
3. **生活日记**：记录博主在日常生活中的所见所闻，如摄影学习与调色思路、在交大生活的记忆、游戏剧情点评、对未来的感悟与想法等.

### 技术路线

本站基于 [Hugo](https://gohugo.io/) 搭建，托管在 [GitHub Pages](https://pages.github.com/) 上，网站源代码托管在 [GitHub 仓库](https://github.com/SJTUYoimiya/SJTUYoimiya.github.io). 本站的主题为博主自行定制，在此，特别感谢 ChatGPT、GitHub Copilot 的付出与支持.

## 网站背景

截至写下此文时，博主仍是一个大四学生，大学四年以来，特别是 23 年 ChatGPT、Copilot 横空出世以后，大模型的帮助使我有机会，更重要的是有一条切实可行的路径去学习各种领域的技术与知识，并付诸实践。在此，首先感谢 ChatGPT、Copilot 对本站的技术支持。

### 建站初衷

说回到建站初衷，在日常的~~拷打大模型~~学习中，博主遇到过各种或简单或复杂的问题，小到一门新语言的语法学习，大到一个项目中的重难点。在发现问题、解决问题的过程中，博主逐渐发现了随手记录的重要性。一方面，网络上的解决方案受限于系统环境与时效性，很多都已不具参考性，搜索有效信息面临着高昂的时间开销与试错成本，且受制于 AI 幻觉，大模型有时并不能很好地解决很具体的技术问题，真正有效的路径需要博主自己一点点摸索；同时，在一些项目中，博主发现有些问题具有一定的重复性，如系统崩溃后的重装、涉及比较底层的技术问题等，在解决此类问题后，一个完整的记录或日志是十分重要的，从此角度出发，个人主页在一定程度上也扮演了随身备忘录的角色，当再次遇到类似问题时，打开网页即可快速查看自己曾经的解决方式与路径。

在生活方面，随着媒体与信息媒介的发展，我们在网络上获取到的信息愈发碎片化、低效化，短视频、营销号等低质量创作内容充斥着互联网环境。虽说有趣的短视频是消磨时间、放松大脑的有效途径，但长期接受此类信息污染，不可避免地给博主的专注力带来了严重影响。又及，大学后不再写非专业性的作文、大模型在组织语言上的进步，种种因素叠加，博主意识到撰写长文的重要性与可观的收益。正巧大四保研之后，博主能够拿出相对更宽裕的时间来整理所见所思，因此在多方考察下，博主最终认定个人主页是一个很好的记录媒介。一则博客性质的内容不像论坛、朋友圈等平台，适合长文章的写作与展示；二来，相较于知乎或大型博客网站，无论是 GitHub Page 或是自建海外站点，这些平台能够一定程度上不受监管限制，尤其是躲避中国大陆对互联网内容的不明审查红线，保证创作的真实性与自由性，也能省下一些不必要的麻烦。

最后，正如当今互联网环境中个人博客势微的现状，博主决定建立个人主页时，主要目标受众仍是未来的自己。正如前文所述，无论是技术问题还是人生感悟，个体间巨大的差异往往会导致博主的经验并不适用于他人，只能当作参考甚至是故事会。因此，如果你碰巧点进本站，且内容有帮助到你的话，那将会是我的不胜荣幸。

### 现实问题

在决定建设个人主页并确定大致内容后，博主面临几个最直接的问题：

1. 经过一定的搜索，博主了解到 Hugo/Hexo/Jekyll 等静态网站生成器可以直接将 markdown 渲染成 HTML 页面。然而，虽然博主已经很熟悉 markdown 语法，但对前端开发技术并无任何了解，即便有大模型的帮助，仍然十分缺乏先验知识与开发经验。
2. 在浏览过主题商店后，博主希望手搓一个真正属于自己的完整主题，从功能性与设计性上贴合个人需求，但不幸的是，这两方面都存在困难。
   - 首先在设计上，虽然博主见过很多设计优秀的网站（如苹果官网、GitHub、一些优秀博客等），但在设计自己的网站美术风格时，面对如何做到「简洁而不简陋」的问题，博主深感仍然缺少艺术细胞与设计思维，对一些元素的表达能力达不到目标水准；
   - 其次在功能性上，将所设想的功能真正落地实现需要一定的技术积累。无论是平衡功能性与开发难度，还是优化网页性能与速度，都需要电脑前的人发挥主观能动性，大模型提供的帮助相当有限。虽然此工作量对行业大佬来说也许是信手拈来，但博主在上手时仍是十分缺乏经验与实战能力的。
3. 最后，还有一个小问题。虽然在当下，个人博客的流量正不断被大型网站蚕食，很多博客大概率只有博主本人会看，但它作为一个开放的平台，仍保留了分享、推广的功能。博主作为一个现实生活中相当内向——甚至可以说确诊为波奇酱——的人，还面临着有可能掉马甲的尴尬问题。基于此，在记录内容，尤其是比较深层、极度个人的想法时，博主也面临着类似日记VS朋友圈的困扰，博主曾尝试在交大的[水源社区](https://shuiyuan.sjtu.edu.cn)内通过日记楼的方式记录生活与思考，但受限于半实名平台的性质，仍然没有勇气发表一些个人想法，最终变成了记流水账的另类朋友圈。
4. 最后，从现实角度出发，由于未来就业方向的不相关性，开发本站的经历极大概率只能算作兴趣爱好甚至玩具。无论出于内容质量还是现实压力，在时间与精力有限的情况下，花费大量时间造轮子都是回报不甚高的行为。

## 关于博主

### 个人简介

博主是上海交通大学 2021 级本科生、2025 级硕士研究生，本硕均就读于数学科学科学院，研究方向为深度学习的理论与应用、AI4Sci 等。截至完成此文，博主正处于大四的最后一个月。博主自知没有什么学术追求，毕业后目标的就业方向主要是算法类，当然，具体的垂直领域方向还需要进一步根据科研与实习进度来决定。

在日常生活中，博主并没有特别突出的爱好，关注的事情也比较杂。博主的主要爱好是日常~~街溜子~~闲逛、摄影，对博主来说，思考构图与调色的时候是为数不多可以从学习与就业的压力中脱离出来的时刻。当然，博主并没有很高超的摄影技术，主要是将它作为放松、休息的媒介与激励自己出门的手段。博主目前持有一台 NIKON Z 30 微单，主要摄影题材为自然风光与城市建筑，活动区域为上海市及周边地区。博主目前在玩的游戏主要是《崩坏·星穹铁道》，同时也会不定期回坑《原神》与《城市天际线》，博主并不是一个热爱游戏的人，玩游戏也是权当消遣，更像是在追更番剧而非游戏竞技。
