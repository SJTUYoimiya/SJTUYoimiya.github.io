本隐私政策描述了本博客（以下简称“本站”或“我们”）如何收集、使用和保护访客（以下简称“您”）的信息。

### 一、个人信息的收集

本站是一个非商业的个人博客，本身不会主动收集您的任何个人敏感信息（例如姓名、电话号码、身份证号码、电子邮件地址等）。

但以下情形可能涉及到您的信息被间接收集：

- **网站统计分析**：本站可能会使用第三方访问统计工具（例如Google Analytics）收集匿名数据，包括IP地址、浏览器类型、访问时长和页面浏览情况，但这些数据无法识别您的个人身份。

### 二、Cookie的使用

- 本站可能通过Cookie收集匿名访问数据，以改进本站的内容和用户体验。
- 您可以通过浏览器设置禁用Cookie，但禁用后可能会影响部分功能。

### 三、第三方服务

本站可能使用以下第三方服务，具体服务条款和隐私政策请参阅相应链接：

- **GitHub Pages**：本站托管于 GitHub Pages，访问日志可能包含您的 IP 地址、浏览器信息和访问时间。这些数据由 GitHub 维护，详见 GitHub 隐私声明。
- **Google Analytics**：本站使用 Google Analytics 统计访问情况。Google Analytics 可能会收集您的浏览器类型、访问页面、停留时间等匿名信息。相关数据由 Google 处理，详见 Google 隐私政策。
- **FontAwesome**：本站使用 FontAwesome 图标库，若从官方 CDN 加载图标，访问时可能会被记录请求信息。详见 FontAwesome 隐私政策。
- **Tailwind CSS / Alpine.js / Tailwind Plus**：这些前端框架仅用于页面样式与交互，不会收集任何用户数据。

本站不会将上述信息用于商业目的。

### 四、信息安全保护

- 本站将采取合理措施保护访客的信息安全，尽可能确保数据不被泄露、滥用或丢失。
- 但由于互联网的复杂性，本站无法对第三方服务提供商的数据安全措施负责。

### 五、对未成年人的保护

- 本站不以未成年人为目标用户，也不会主动收集或存储任何未成年人的个人信息。
- 如未成年人未经监护人同意在本站提供个人信息，请立即联系本站删除。

### 六、隐私政策的更新

- 本站可能不定期更新本隐私政策，更新内容会在本页面发布。
- 若您继续访问本站，则视为您接受更新后的隐私政策。

### 七、联系我们

如果您对本隐私政策有任何问题或建议，请在本站的 [GitHub 仓库](https://github.com/SJTUYoimiya/SJTUYoimiya.github.io)上提交 issue 或通过[电子邮件](mailto:sjtuwzh@gmail.com)与我联系。
